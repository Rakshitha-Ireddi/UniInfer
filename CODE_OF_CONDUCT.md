# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**In short:** be respectful and constructive. Critique ideas and code, never people. Welcome newcomers.
Harassment, discrimination and personal attacks are not tolerated in any project space: issues, PRs,
discussions or any other channel connected to the project.

**Reporting:** contact the maintainer through the email on their GitHub profile, or open a private
security advisory on this repository. Reports are handled confidentially. Maintainers may remove
contributions or restrict participation of anyone who violates this code.
